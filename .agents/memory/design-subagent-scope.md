---
name: Design subagent scope
description: The design subagent reskins unless explicitly told to redesign each panel by name
---

When the UI already exists, a design subagent given a general "make this beautiful" brief returns a theme swap: new tokens in the CSS file plus light edits to one or two components, and it will say so itself. Panels keep their old layouts.

**Why:** observed directly on the analog-finder planner page — the first pass replaced the placeholder red theme, added provenance colours, a legend and a 404 page, and touched only two panel components.

**How to apply:** when restyling an existing multi-panel UI, follow up with an explicit per-component list (each panel named, plus what each one must communicate) and ask it to keep hierarchy, scanability and selection state legible in each. Name the constraint that features, props, data sources and logic must not change. One follow-up with the full list produced the intended result.
